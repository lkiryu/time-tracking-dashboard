# Time Tracking Dashboard

Dashboard desenvolvido com **React, JavaScript e Tailwind CSS**, permitindo visualizar e acompanhar diferentes atividades em períodos distintos.

## Funcionalidades

- Exibição de informações sobre diferentes atividades.
- Alternância entre visualizações diária, semanal e mensal.
- Atualização dos dados de acordo com o período selecionado.
- Gerenciamento de estado compartilhado utilizando Context API.
- Componentes reutilizáveis para organizar a interface.

## Tecnologias utilizadas

- React
- JavaScript
- Tailwind CSS
- Context API
- Vite

## Como executar o projeto

1. Clone o repositório:

   ```bash
   git clone https://github.com/lkiryu/time-tracking-dashboard.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd time-tracking-dashboard
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inicie o servidor de desenvolvimento:

   ```bash
   npm run dev
   ```

## Objetivo do projeto

O objetivo foi desenvolver um dashboard utilizando componentes reutilizáveis, praticando gerenciamento de estado global, organização de componentes e construção de interfaces responsivas com React.
